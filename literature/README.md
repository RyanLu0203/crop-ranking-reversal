# Literature

Issue #3 rebuilds the verified literature foundation from DOI-resolved metadata and inspected full text. Teacher and historical references are discovery leads only.

- annotated_synthesis.md organizes evidence by claim rather than by paper.
- references.bib at repository root is the canonical citation file.
- evidence_registry/literature_registry.csv records full-text verification, limitations, and permitted uses.
- audits/literature_search_log.md records queries, screening, and version checks.
- audits/literature_quality_matrix.csv records inclusion, exclusion, and quality.
- audits/novelty_comparison_matrix.csv governs any contribution claim.

No complete manuscript Literature Review is written here; that work remains in Issue #9.
