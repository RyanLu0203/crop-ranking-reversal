# Repaired theory package

This directory is the canonical positive output of Issue #2. It preserves the teacher Draft's multi-crop stochastic architecture while replacing invalid general claims with proved results, explicitly restricted propositions, diagnostics, or preregistered simulation hypotheses.

- canonical_theorem_set.md: readable canonical model and result set
- canonical_theorem_set.tex: standalone compilable theorem document
- proofs.md: complete proofs and boundary arguments
- assumptions_definitions_notation_crosswalk.csv: Draft-to-canonical crosswalk
- theorem_transition_registry.csv: disposition of every audited Draft result
- theory_to_simulation_map.csv and theory_to_empirical_map.csv: downstream contracts
- supervisor_memo_en.md and supervisor_memo_zh.md: bilingual decision memo

No file in baselines/teacher_draft is modified by this package.
