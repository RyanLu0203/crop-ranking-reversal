# Decisions for supervisor review

This note is deliberately excluded from the manuscript and Supplementary
Information.

The following items require supervisor confirmation before any submission:

- final author order;
- corresponding author;
- final institutional affiliations;
- final CRediT contribution statement;
- target journal and any journal-specific article format;
- whether the current structural experiments should be extended with
  farm-level or decision-maker data.

The current manuscript uses a provisional author block and a concise
contribution statement solely for formal supervisor review. It should not be
treated as a final authorship decision or as publication-ready.
