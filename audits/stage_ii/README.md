# Stage II reconstruction control

## Scope

This directory is the GOAL-11 scientific reconstruction blueprint for GitHub
Issue #21. It audits the Stage I baseline at commit
`4d6c14d48b6eb76cf0612c837341d3ee2afbf0d0` and specifies the evidence that
later Stage II issues must produce. It does not rewrite the manuscript, alter a
theorem, rerun a simulation, create a figure, or extend the empirical data.

## Execution control

- Baseline branch and commit: `main` at `4d6c14d`.
- GOAL-11 working branch: `codex/issue-21-stage-ii-blueprint`.
- Active issue: #21 only.
- Required outputs: current weakness audit, theory gap analysis, confirmatory
  simulation redesign, empirical expansion plan, six-group figure blueprint,
  and manuscript restructuring roadmap.
- Stop condition: this package passes its validator and repository checks and is
  submitted for supervisor review. GOAL-14, GOAL-12, GOAL-13 and GOAL-15 remain
  unexecuted.

## Canonical files

- `scientific_gap_audit.md`: evidence-backed diagnosis and reconstruction thesis.
- `theory_gap_matrix.csv`: positive theory targets, proof classes and downstream tests.
- `simulation_redesign_plan.md`: controlled confirmatory experiment architecture.
- `empirical_expansion_plan.md`: model-linked observational validation architecture.
- `figure_redesign_plan.md` and `figure_blueprint.csv`: six claim-led figure contracts.
- `manuscript_restructuring_roadmap.md`: gated final argument structure.
- `reconstruction_traceability.csv`: five research questions mapped end to end.
- `acceptance_matrix.csv`: requirement-level proof of GOAL-11 completion.

## Dependency and stop order

The project-control order is binding:

1. GOAL-11 / Issue #21: blueprint (this package).
